# AHP GT – Pemilihan Mobil (3D Cinematic)

Aplikasi web interaktif Sistem Pendukung Keputusan (SPK) untuk pemilihan mobil dengan metode **Analytic Hierarchy Process (AHP)** dan visualisasi **3D Cinematic** menggunakan Three.js.

## ✨ Fitur Utama
- **Visualisasi 3D Interaktif**: Model 3D mobil dengan efek pencahayaan sinematik, pintu gunting interaktif, dan animasi rotasi/scroll.
- **Perhitungan AHP Real-time**:
  - Bobot Prioritas Kriteria (Style, Keandalan, Konsumsi BBM).
  - Bobot Lokal Alternatif (Avanza, Xenia, Ertiga, Grand Livina).
  - Matriks Kontribusi & Perhitungan Konsistensi Rasio (CR & $\lambda_{max}$).
  - Peringkat Akhir & Penentuan Mobil Terbaik.
- **Scroll-driven Storytelling**: Animasi kamera dan transisi informasi berbasis scroll.
- **Responsive & Modern Design**: Mendukung tampilan desktop dan mobile.
